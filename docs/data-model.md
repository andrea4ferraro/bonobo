# Position Model

Each liquidity position contains:

- Pool
- Token A
- Token B
- Amount A
- Amount B
- Current Value (USD)
- Profit/Loss (USD)

Example

```json
{
  "pool": "ETH/USDC",
  "token_a": "ETH",
  "token_b": "USDC",
  "amount_a": 0.45,
  "amount_b": 780,
  "value_usd": 1820,
  "profit_usd": 120
}
```
